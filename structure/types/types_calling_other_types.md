Quick look at what file `__type__` call other file `__type__` 

```sql
SELECT
    o1.object_type AS source_type,
    o2.object_type AS target_type,
    COUNT(*) 
FROM outgoing_references r
JOIN objects o1
    ON r.source = o1.sno_id
JOIN objects o2
    ON r.target = o2.sno_id
GROUP BY
    source_type,
    target_type
ORDER BY
   count(*) DESC;
```
